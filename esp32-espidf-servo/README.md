# Приклад використання серводвигуна SG90

Реалізовано 2 варіанта:
1. З використанням MCPWM (Motor Control PWM) таймера
2. За допомогою LEDC (LED Control), timer + channel.

Для вибору варіанта використовується макрос MCPWM_SERVO (0/1)
