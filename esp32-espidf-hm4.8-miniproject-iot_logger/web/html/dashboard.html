Field notes. This console speaks MQTT over WebSocket directly from the browser — no external library, no server. Point it at the same broker as the firmware's CONFIG_IOT_LOGGER_MQTT_BROKER_URI, but on the websockets listener, not the raw TCP one.

Mosquitto needs a second listener alongside the existing one — add to mosquitto.conf: listener 9001 / protocol websockets, then restart the broker.

If "LINK" refuses to connect from a page opened over https://, that's the browser blocking insecure ws:// from a secure page (mixed content) — save this file and open it locally (file://), or serve it from your own LAN, to reach the broker directly.
