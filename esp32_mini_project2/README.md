# Адаптивна фара та система аварійної сигналізації

1. При натисканні кнопки, вмикається аварійна сигналізація. При повторному натисканні, вимикається.
2. Адаптивна фара реалізована з PWM, що дозволяє змінювати яскравість світлодіода враховуючи освітлення.
